# 💻 Programação Orientada a Objetos (POO)

Este repositório contém o conjunto de atividades e projetos desenvolvidos durante a disciplina de **Programação Orientada a Objetos**.

O foco é a aplicação prática dos pilares da POO para criar sistemas modulares e eficientes como parte da minha formação em **Análise e Desenvolvimento de Sistemas**.

 # 📚 Conteúdo e Atividades

 ---
 
<img align="right" width="350" src="https://raw.githubusercontent.com/SimoneSoaress/SimoneSoaress/main/SimoneCorpoInteiro.png" style="border-radius: 50%;">

As evolução das atividades exploram a modelagem de sistemas reais através de objetos:

* **Fundamentos de Classes**: Implementação inicial das classes `Funcionario` e `ContaCorrente`.
* **Encapsulamento**: Desenvolvimento da lógica de `ContaBancaria` para proteção de dados.
* **Abstração e Contratos**: Exercícios avançados sobre classes abstratas e interfaces.
* **Modelagem de Software**: Criação de diagramas UML para planejamento de arquitetura.
